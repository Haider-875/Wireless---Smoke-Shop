# PLAN 04-01: Responsive Design and Animations

## Objective
Fine-tune responsive behavior across Mobile (<576px), Tablet (768px-991px), and Desktop (≥992px, ≥1200px, ≥1400px), ensuring touch target accessibility, container gutters, smooth hover elevation (`-translateY(2px)`), glow transitions, and responsive typography.

## Tasks
1. **Responsive Viewport Styles & Micro-Animations**:
   - Refine `public/assets/css/bugs-theme.css`:
     - Mobile container padding and header heights.
     - Smooth card hover lift and border transition.
     - Mobile touch targets (minimum 44x44px for buttons and navigation items).
     - Responsive adjustments for `.glow-gold` overlay on narrow screens.
     - Fluid margins and gutters for `.bugs-cta-card` and process steps.
2. **Interactive State Polish**:
   - Refine active link styles, focus indicators, and offcanvas backdrop transitions.
3. **Automated Verification**:
   - Add feature tests in `tests/Feature/ResponsiveAndAnimationTest.php` to verify responsive classes, meta viewport, and styling hooks.
4. **Phase 4 Summary & Execution Report**:
   - Create `04-01-SUMMARY.md` and `phase-4-execution-report.md`.

## Acceptance Criteria
- [ ] Viewport `<meta name="viewport" content="width=device-width, initial-scale=1">` verified.
- [ ] Responsive grid transitions cleanly:
  - Service grid: 1 col on mobile (<768px), 2 cols on tablet (768px-991px), 3 cols on desktop (≥992px).
  - Process steps: stacked on mobile/tablet, 3 cols on desktop (≥992px).
  - CTA card: stacked on mobile, row on tablet/desktop.
- [ ] Button hover transitions `-translateY(2px)` and card border glow effects verified.
- [ ] 100% test pass rate with 0 errors.
- [ ] Zero Tailwind CSS usage.
