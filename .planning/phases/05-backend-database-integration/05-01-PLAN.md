# PLAN 05-01: Backend and Database Integration

## Objective
Implement backend data persistence and API endpoints for:
1. Phone and tablet repair quote inquiry requests (`POST /repairs/quote`) with database storage and FormRequest validation.
2. Server-side session-backed Cart API (`GET /api/cart`, `POST /api/cart/add`, `POST /api/cart/update`, `POST /api/cart/remove`, `POST /api/cart/clear`) with item calculation and validation.
3. UI integration in `/repairs` view for submitting a repair quote inquiry or direct calling.

## Tasks
1. **Database Migration & Eloquent Model for Repair Inquiries**:
   - Create `database/migrations/2026_11_12_000001_create_repair_inquiries_table.php`.
   - Fields: `id`, `name`, `phone`, `device_model`, `service_needed`, `notes`, `status` (default: 'pending'), `timestamps`.
   - Create `app/Models/RepairInquiry.php`.
2. **FormRequest Validation**:
   - Create `app/Http/Requests/RepairQuoteRequest.php` (validates `name`, `phone`, `device_model`, `service_needed`).
3. **Repair Quote Inquiry Controller Endpoint**:
   - Add `storeQuote(RepairQuoteRequest $request)` to `RepairController.php`.
4. **Session Cart Controller & Routes**:
   - Create `app/Http/Controllers/CartController.php` with session storage for items.
   - Register routes in `routes/web.php`.
5. **Interactive Quote Modal / Form on `/repairs`**:
   - Add a "Request a Quote" modal to `resources/views/pages/repairs.blade.php` with CSRF protection and AJAX/form submission.
6. **Automated Verification**:
   - Create `tests/Feature/BackendIntegrationTest.php` to verify:
     - Repair quote submission persists in MySQL.
     - Validation errors occur on missing fields.
     - Cart API endpoints add, update, remove, and clear items accurately.
7. **Execution Report**:
   - Generate `05-01-SUMMARY.md` and `phase-5-execution-report.md`.

## Acceptance Criteria
- [ ] MySQL table `repair_inquiries` migrated and populated via feature tests.
- [ ] `POST /repairs/quote` validates input and stores inquiry in database.
- [ ] Cart API calculates correct counts and subtotals in session.
- [ ] All automated tests pass with 100% success.
- [ ] Zero Tailwind CSS usage.
