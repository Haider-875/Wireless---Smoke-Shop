# PLAN 02-01: Design System & Shared UI Components

## Objective
Implement the complete visual design system tokens in `bugs-theme.css`, create the 21+ Age Verification Gate modal, the slide-out Cart Bag Offcanvas drawer, the glassmorphic dynamic Navbar with mobile offcanvas navigation, and the comprehensive footer.

## Tasks
1. **Design Tokens & Theme CSS**: Expand `public/assets/css/bugs-theme.css` with exact color tokens, glassmorphism, buttons, cards, typography utilities, and animations matching the reference.
2. **Age Verification Modal Component**: Create `resources/views/components/age-modal.blade.php` with 21+ age check, backdrop blur, and localStorage persistence (`bugs-age-confirmed`).
3. **Cart Bag Offcanvas Drawer Component**: Create `resources/views/components/cart-drawer.blade.php` with item counter badge, empty state, sample items, subtotal calculation, checkout CTA, and quantity controls.
4. **Interactive Navbar Component**: Enhance `resources/views/components/navbar.blade.php` with exact brand typography `BUGS.`, phone pill link, Bag button with live counter badge, navigation items (`Shop all`, `Vapes`, `Glass & Pipes`, `Repairs`, `Visit us`, `Your orders`), and mobile menu offcanvas.
5. **Comprehensive Footer Component**: Expand `resources/views/components/footer.blade.php` with brand details, address, hours, phone, Google Maps directions link, Instagram link, shop category links, and 21+ legal compliance notice.
6. **Master Layout Integration**: Wire all components into `resources/views/layouts/app.blade.php`.
7. **Vanilla JS Updates**: Update `public/assets/js/bugs-app.js` with age confirmation logic, cart drawer triggers, and scroll listeners.
8. **Automated Verification**: Add tests in `tests/Feature/SharedComponentsTest.php` to verify all components render properly without errors.

## Acceptance Criteria
- [ ] Age verification modal renders on first visit and hides upon confirmation (`localStorage.setItem('bugs-age-confirmed', 'yes')`).
- [ ] Cart drawer opens via Bootstrap Offcanvas and displays empty state / item list with subtotal.
- [ ] Navbar dynamically adds backdrop blur and background opacity on scroll (`window.scrollY > 16`).
- [ ] Footer renders store information, social links, directions link, and compliance notice.
- [ ] All automated tests pass with 0 errors.
- [ ] Strict absence of Tailwind CSS and unnecessary frameworks.
