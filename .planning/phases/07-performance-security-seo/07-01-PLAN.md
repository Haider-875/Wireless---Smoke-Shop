# PLAN 07-01: Performance Optimization, HTTP Security Hardening, and Technical SEO

## Objective
Implement production-grade technical SEO (OpenGraph, Twitter cards, meta descriptions, Schema.org LocalBusiness & Product JSON-LD, sitemap, robots.txt), robust HTTP security headers (CSP-friendly nosniff, frame options, XSS protection, referrer policy), route rate limiting on sensitive forms, and resource/asset performance hints.

## Tasks
1. **Technical SEO & Structured Data**:
   - Update `resources/views/layouts/app.blade.php`:
     - Add dynamic meta description, canonical link, and robots meta tags.
     - Add OpenGraph meta tags (`og:title`, `og:description`, `og:url`, `og:image`, `og:site_name`, `og:type`).
     - Add Twitter Card meta tags (`twitter:card`, `twitter:title`, `twitter:description`, `twitter:image`).
     - Add Schema.org JSON-LD structured data for `ElectronicsStore` / `LocalBusiness` with St. Louis address, geo coordinates, telephone, hours, and catalog links.
   - Update `resources/views/pages/shop/show.blade.php`:
     - Add Schema.org `Product` JSON-LD with price, availability, and description.
   - Generate `public/sitemap.xml` and update `public/robots.txt` with sitemap reference and admin protection.
   - Add `/sitemap.xml` dynamic fallback route if needed.

2. **HTTP Security Hardening & Rate Limiting**:
   - Create `app/Http/Middleware/SecurityHeadersMiddleware.php`:
     - Set `X-Content-Type-Options: nosniff`.
     - Set `X-Frame-Options: SAMEORIGIN`.
     - Set `X-XSS-Protection: 1; mode=block`.
     - Set `Referrer-Policy: strict-origin-when-cross-origin`.
     - Set `Permissions-Policy: camera=(), microphone=(), geolocation=()`.
   - Register the middleware in `bootstrap/app.php` across the web middleware stack.
   - Apply rate limiting throttles to sensitive endpoints (`/repairs/quote`, `/checkout`, `/admin/login`).

3. **Performance & Asset Loading Hints**:
   - Add `dns-prefetch` and `preconnect` hints for Google Fonts in `resources/views/layouts/app.blade.php`.
   - Ensure all image tags have `loading="lazy"` and `decoding="async"`.

4. **Automated Verification**:
   - Write comprehensive tests in `tests/Feature/PerformanceSecuritySeoTest.php`:
     - Verify SEO meta tags, OpenGraph, and Twitter tags are present on home, repairs, and shop pages.
     - Verify Schema.org JSON-LD is valid and contains expected store information.
     - Verify HTTP response security headers are returned.
     - Verify robots.txt and sitemap.xml are accessible.
     - Verify rate limiting or validation protection on quote/checkout.

5. **Phase Documentation**:
   - Generate `07-01-SUMMARY.md` and update `.planning/STATE.md` and `.planning/ROADMAP.md`.

## Acceptance Criteria
- [ ] SEO meta tags and OpenGraph tags render correctly on all major pages.
- [ ] Schema.org structured data validates as valid JSON-LD.
- [ ] Security headers (`X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`) are emitted in HTTP responses.
- [ ] Robots.txt and sitemap are valid and live.
- [ ] All 26+ tests pass with 100% green assertions.
